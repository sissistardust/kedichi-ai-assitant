# Kedichi AI Assistant

Welcome to **Kedichi AI Assistant**, an AI-powered virtual assistant for the fictional pet store **Kedichi**.

## About

Dedè is a Ragdoll cat and the official AI assistant of Kedichi. She helps customers by answering questions about products, shipping, returns, store policies, and other customer support topics using the store's knowledge base.

## Project Goals

- Build an AI assistant using OpenAI models.
- Implement Retrieval-Augmented Generation (RAG).
- Answer questions based on company documents.
- Provide accurate and helpful customer support.

## Planned Features

- AI chat interface
- Knowledge base with PDF documents
- Retrieval-Augmented Generation (RAG)
- OpenAI API integration
- Cloud deployment

## Tech Stack

- Python
- OpenAI API
- GitHub
- Cloud deployment
